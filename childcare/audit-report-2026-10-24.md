Date checked: 2026-10-24
County: Lehigh County, PA. Category: child care / family support.
Method: pilot list built from public directories (PA 211, secondary
directories); every item then checked against the organisation's own
website/page, via public web search and page-text fetches. Own site
beats directory; directory beats a third-party aggregator. Raw checks
are in checks-batch1.md (items 1–8), checks-batch2.md (9–16), and
checks-batch3.md (17–24 plus straddle items), same folder.
Status: NOT SENT YET. Nothing in this report has been sent to PA 211 or
to any organisation. Keith's accept checkpoint comes before any outward
report. This audit does not refer to Keith as a local resident, and it
records no information about individual children.
Counts note: large multi-site providers (LVCC, CSC) are counted once as
organisations, with example sites noted separately — not every site as
a separate listing.

## What this report does NOT claim
- No organisation is called closed or defunct. ABC Children's Day Care
  and Caring Learning Center are UNVERIFIED for the reasons given
  (no own website found; own-site fetch failed) — neither is a closure
  finding, and both should be rechecked before any outward report.
- Hours, ages, and subsidy routes that appear only in directories or
  aggregators are labelled directory-only in the table and must not be
  published as own-site fact. This is common in this category: several
  organisations' own pages state no hours at all, while directories
  confidently give them.
- Waitlist status is reported only where an own site states it (CSC:
  often a waiting period after application; Traci's: currently
  enrolling). No other waitlist position is claimed.
- This report gives no child care, health, or benefits advice, and
  records no information about individual children.
- No domestic-violence safe-house address appears in this report or
  its check files. If a directory leaks a confidential location, report
  it privately to the directory with the address redacted — never
  republish it as a correction.
- School-year vs summer hours: where a programme's own page did not
  distinguish them, no seasonal claim is made.
