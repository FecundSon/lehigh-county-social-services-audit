# Lehigh County Utilities Assistance — Pilot List
County: Lehigh County, PA. Category: utilities assistance (LIHEAP, shut-off
help, fuel funds, weatherization, water/sewer assistance).
Source directory: PA 211 / search.pa211.org, supplemented from utility and
administrator programme pages. Date compiled: 2026-10-24.
Status: DRAFT FOR KEITH'S ACCEPTANCE ONLY. Nothing sent to PA 211 or any
organisation. Own-site checks are in checks-batch1–4.md; verdicts are in
audit-report-2026-10-24.md. This list does not refer to Keith as a local
resident.

Note on counting: utilities assistance is programme-based, not
premises-based, so several listings are the same programme reached through
different doors (e.g. LIHEAP via DHS, via the County Assistance Office, and
via a utility). Those are listed separately because directories list them
separately, and the audit flags the duplicates rather than hiding them.
