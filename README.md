# Lehigh County, PA — Social Services Listing Audits

**All categories checked: 2026-10-24. Status: published here first for
statewide PA 211 and the organisations to respond to. Nothing in this
audit has been sent to PA 211 or any organisation as a direct message,
except where a category's folder notes a send.**

## What this is
One repo, one county, twelve public categories — a dated curation audit
of public social-services listings for Lehigh County, PA, checked
against the organisations' own websites and other public listings. It
is not a replacement directory: it does not claim to be a current list
of open services, and it should not be used as one without checking
with the organisation or PA 211 first.

Each category folder holds three files: a README with the headline
corrections, the full audit report with evidence and sources, and the
original pilot list it was checked against.

## Not in this repo, by design
**Domestic violence services are not published here.** That audit is a
private report only: safe-house and other confidential locations are
never published, and any directory leak of a confidential location is
reported privately to the directory, with the address redacted. Do not
add domestic-violence shelter addresses to this repo.

## Method and limits — please read before using this
- Public web search and page-text fetch only, 2026-10-24. No
  organisation, PA 211, or anyone else was contacted for these audits.
- An organisation's own website is treated as authoritative over
  third-party directories.
- **No service is called defunct or closed in these audits.** A failed
  or missing page is reported as unverified, never as closure.
- Fares, schedules, waitlists, funding windows, and seasonal dates are
  date-stamped to 2026-10-24 and must not be presented as permanent.
- For mental health, substance use, and legal aid, contact information
  only was audited — no advice was rewritten.
- These audits were prepared with AI assistance. Corrections,
  challenges, and updates from PA 211 or the organisations themselves
  are welcome — that is the point of publishing them here first.

## Recipient note
Lehigh County listings live in the **statewide PA 211 database**, not
with PA 211 East (a United Way of Lancaster County programme serving
Berks and Lancaster; Lehigh coverage ended July–October 2025). Lehigh
corrections go to statewide PA 211.
